## Annotation inspection

See `inspected_examples.json` for five actual source units, exact token columns, metadata and resulting derived records. First source unit retains `[PASSÉ-PROCHE]`, `[carte-france]`, `position-neutre`. Pointing such as `PNT[fin]` and uncertain `PNT[changement-temporel?]` is preserved. The second and third source units repeat the same long French translation; their target forms are concatenated in source order and flagged, with both segment IDs retained. Another repeated translation is merged later. This is a documented derived utterance experiment, not a claim that alignment has been linguistically verified. MISC retains time alignment, roles, nonmanuals, nondominant-hand holds and English glosses in raw annotations; the sequential target omits these channels and cannot express full LSF.

Splits union common recordings, document-scoped signer IDs, exact normalized French, exact gloss sequences and near-French matches (SequenceMatcher >= .90 for strings >=20 chars). Same-source provenance is retained but cannot be disjoint with a single-source corpus. Cross-corpus signer identities are unknown; the split is recording-disjoint, not independently verified signer-disjoint. No source's original `-test.conllu` designation is represented as its official translation split.
