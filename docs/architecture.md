# Architecture MVP
The authoritative wire contract is INTEGRATION_CONTRACT.md. Pydantic v2 models are exported from backend.app.schemas; API implementation belongs to the backend engineer. French lookup resolves glossary IDs to manifest entries and positional JSON motion assets. All clocks use milliseconds and the shared rig identifier is signaculture-v1.

Six controlled French concepts link to original synthetic technical fixtures. They enable software integration only. Linguistic review and animation review remain pending; cleared CC0 fixture rights do not imply approved signing. TranslationDraft fixes translation_validated to false and AnimationPlan fixes publication permission to false. Review persistence and publication gates belong to the API service, not model construction.

Local preview resolves registered relative paths only. Production assets need authorized provenance, animation review and linguistic approval. Optional experiments produce separate intermediate artifacts, never silently replacing registry data. See experiments/README.md for extraction coordinate conventions, unavailable Animics retargeting and explicit local emotion2vec inference.
