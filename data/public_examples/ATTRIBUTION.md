The original 2.447-second source clip is included as `bonjour.webm`. The derived file `data/approved_motion_assets/LSF_BONJOUR_COMMONS.json` contains MediaPipe body, finger and facial measurements, transformed to a hip-centred, Y-up coordinate system and an approximate wrist-anchored hand depth. This extraction and the procedural avatar are modifications, not the original performance. Neither source creators nor Wikimedia endorse this project. The reconstructed motion remains pending linguistic and animation review.
